# Static exports, social orchestration and measured experiments

## Static composition

Design studio builds an editable JSON layer document from a current copy revision and approved assets only. Placement uses the original normalized raster bytes, checked against their stored SHA-256. It does not ask an image model to redraw logos or products. Layout versions are immutable; editing supersedes the preceding version. Copy approval and visual approval are separate. Brand/version changes or asset revocation block future export. Stale edits fail rather than overwrite another editor's work.

Saved draft previews are permitted before approval. Final PNG/SVG/JSON exports require approved current copy, approved current composition, current confirmed brand and still-approved assets. Every render rechecks permissions after asynchronous storage work. PNG is rasterized by Sharp; SVG escapes text and embeds trusted raster bytes only, with no remote URLs or scripts. Text fitting is conservative approximate wrapping, not professional font measurement; overflow refuses export. Sizes: 1080×1080, 1080×1350, 1080×1920 and 1200×628. These are canvas presets, not a guarantee of every platform's current media rules. Downloads cannot be recalled after revocation.

Authenticated downloads and private immutable saved PNG exports are implemented. The Gemini supporting-artwork workflow is described in [image production](IMAGE-PRODUCTION.md); actual social media transfer remains unimplemented. No provider call or AI credit is consumed by deterministic composition.

## Social safety boundary

`configuredSocialAdapters()` intentionally returns no adapters. Adding keys or setting `SOCIAL_EXECUTION_ENABLED=true` does not activate fake publishing. Actual adapters and OAuth must be implemented and tested before the gate is enabled. Account records are only created through the internal verified-connection contract; there is no public arbitrary-token ingestion endpoint.

Scheduling binds an exact approved current revision, frozen payload/hash, account and timezone. Rescheduling cannot change that payload hash. The initial text contract accepts Facebook/LinkedIn copy only; Instagram and media-dependent formats fail closed until immutable media export delivery exists. At execution, the worker rechecks brand, approval, snapshot, account status/expiry and placement before marking SUBMITTING. Provider-specific permission verification remains part of the future adapter. Invalid persisted payloads and unreadable credentials stop that item without repeatedly blocking the queue. Safe retries require the adapter to establish that no publication occurred, with a maximum of three submission attempts. Timeouts, process death and malformed receipts become NEEDS_RECONCILIATION, never blind retries.

The worker now checks one due uncertain publication per social tick using lookup only. Each lookup has a two-minute lease and a 45-second adapter timeout. It makes at most five checks with one-, two-, four- and eight-minute delays between inconclusive results. Counts and eligibility times persist across restarts. Empty results do not prove non-publication; timeouts and malformed receipts remain unconfirmed. Invalid snapshots, expired accounts and unavailable decryption stop lookup for operator attention. A crashed fifth check is also marked stopped. No branch resends the post.

Before saving a receipt, the worker checks the original payload hash, destination account, encrypted credential, account status/expiry and current lease again. Stale responses cannot finish another worker's attempt. Receipt persistence and its audit event share one transaction. Publication history shows the lookup count, next eligible check or operator-review requirement without exposing tokens or payloads. Official adapters must still prove account/content read-back; this contract alone is not platform acceptance.

### Operator lookup recovery

After investigating a stopped outcome, a privileged server operator can use `scripts/resume-social-lookup.ts` with `--publication`, `--operator`, `--evidence` and explicit `--resume-lookups`. Evidence must describe the account/snapshot or credential repair and must not contain secrets. The command refuses active leases, confirmed outcomes, invalid snapshots and unusable credentials. It records the previous check count and operator evidence before reopening at most five lookup checks; concurrent/replayed requests do not reset an already-open window. It never assigns an external post ID, changes the uncertain status, submits content or settles credits. There is no customer HTTP endpoint for this operation. A dedicated operator console, alerts and provider-specific investigation tools remain pending.

New copy versions, rejection, unscheduling and brand changes invalidate queued publication. Edits/disconnect are blocked during uncertain or in-flight submission so they cannot imply cancellation of a remote write already made. Disconnection otherwise cancels queued work and erases the local token. Platform-level token revocation requires its future adapter.

## Metrics and learning

Snapshots preserve unsupported metrics as null, not zero, and are deduplicated by publication/observation/definition. Dashboard totals use only the latest lifetime reading for each of at most 500 recent published posts, separately grouped by account and metric definition. They are not date-range increments. Coverage/staleness is visible; summed reach is not unique people and engagement is not conversions. Metric sync is leased, bounded, age-aware and stops after repeated failures or thirty days; actual platform mapping remains unimplemented.

An experiment proposal requires two formats on one account/definition, at least five mature posts per format and 1,000 impressions each. A relative/absolute observed engagement-rate difference only produces a hypothesis. Nonrandomized audience/topic/timing differences may explain it; it is not statistically validated causal learning. Promotion requires explicit human confirmation for the current brand, creates one scoped experiment memory and invalidates offered generation quotes. Reverting removes exactly that memory. It does not train model weights, rewrite skills or initiate publication/spending. Weekly planning and bounded copy authorization exist; mixed-media autopilot and measured improvement remain incomplete.

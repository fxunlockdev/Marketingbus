# Higgsfield transport research — 18 October 2026

These verified public contracts support the next implementation step. They are not an adapter, account-acceptance result or authorization to spend. The generated-shot registry remains empty.

## Verified contracts

- Authentication is server-side `Authorization: Key KEY_ID:KEY_SECRET`. Credentials do not imply access to every model. [Authentication](https://docs.higgsfield.ai/docs/authentication).
- Model-specific documentation takes priority over the supplementary OpenAPI catalog. The public console redirects to `open.higgsfield.ai`; absent models in OpenAPI are not proof of unavailability. [Documentation index](https://docs.higgsfield.ai/docs/llms.txt).
- Seedance 2.5 text-to-video uses `POST https://api.higgsfield.ai/bytedance/seedance-2.5/text-to-video`. Its model-specific schema documents prompt, integer duration 4–30 seconds, resolution 480p/720p/1080p, selected aspect ratios, MP4/MOV and `generate_audio`. Our current shot path permits at most eight seconds and silent normalized H.264; do not expand it implicitly. The playground sample mentions `bitrate_mode`, but the documented parameter table does not. Do not add that undocumented field. [Seedance API](https://open.higgsfield.ai/models/bytedance/seedance-2.5/text-to-video/api-reference).
- Kling 3.0 Standard text-to-video uses `POST https://api.higgsfield.ai/kling-video/v3.0/std/text-to-video`. Parameters include prompt, integer duration 3–15 seconds, sound on/off, CFG scale, single/multiple-shot selection and aspect ratio. A silent single-shot implementation must explicitly set its output parameters rather than inherit sound-on defaults. [Kling API](https://open.higgsfield.ai/models/kling-video/v3.0/std/text-to-video/api-reference).
- Submission returns a UUID request ID and status URL. Status values are queued, in_progress, completed, failed, nsfw and canceled; completed video uses `video.url`. Shared status responses do not document model/account/final-USD fields. Preserve trusted local submission binding instead of inventing those response fields. Validate any returned URL before use. [Request lifecycle](https://docs.higgsfield.ai/docs/concepts/requests), [status schema](https://docs.higgsfield.ai/docs/api-reference/requests/get-request-status).
- Generation accepts an `Idempotency-Key` tied to one account intent and identical endpoint/body/webhook. Replaying is documented to return the original ID; parameter changes are rejected. This does not justify changing the existing unknown-outcome policy without a durable request journal and replay tests. [Idempotency](https://docs.higgsfield.ai/docs/concepts/idempotency).
- Account-specific estimates use the same model parameters and return decimal-string credits/USD. Failed/moderated requests are described as uncharged; queued cancellation is refundable. Output retention is at least seven days. The status contract does not contain a final expense receipt. Keep an estimate distinct from a reconciled charge; never label a marketing starting rate or estimate as verified final expense. [Billing and retention](https://docs.higgsfield.ai/docs/concepts/billing-and-retention).

## Engineering consequences

Current model identifiers in `shotRate` disallow `/`; use a reviewed alias-to-fixed-endpoint mapping or a deliberate schema/migration update, never an arbitrary endpoint from tenant input. Persist exact request parameters/hash, account credential identity, provider job ID and cost evidence. Bind polling to that record across credential/configuration changes. Downloads need an explicit trusted-host policy, public-network controls, byte/time limits and no credential forwarding. Do not infer download allowlists from documentation example CDNs.

The first transport still needs implementation, tests and a verified expense policy; these notes do not close that gap. Live testing additionally needs the user's private credentials, account-specific model/rate access, explicit new spending budget and storage/decoder readiness. No authenticated provider call was made for this research.

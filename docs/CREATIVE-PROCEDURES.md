# Business-specific creative procedures

Implemented pipeline: reviewed corrections → quoted reflection → explicit one-call authorization → worker → source-linked proposals → human activation → matching-task knowledge context → retirement or automatic exclusion when evidence changes.

The existing `BrandAnalysis` job ledger now distinguishes `BRAND` from `SKILL_REFLECTION`. Reflection shares its supplier budget reservation, credit settlement, expired-lease recovery, retention fences and operator reconciliation. Brand extraction cannot apply or accept a reflection. No new hosted service, Graphiti, embeddings, autonomous code or recurring paid job is added.

## Evidence and scope

- Only a business's current confirmed brand version, latest approved creative revisions, named approvers and corrections within 90 days qualify. At least two distinct items on one destination are required.
- Up to eight episodes / 24 KB, four quotes per business/day; common emails, URLs, tokens and international phone numbers are redacted. This is minimization, not guaranteed anonymization. No model transcript or source-pack executable is run.
- Structured proposals contain a scenario, instruction, limitation, review check and exact feedback/approved-result quotes. Invented/repeated/cross-channel references fail validation. These checks establish provenance, **not semantic correctness**.
- Visual-direction proposals inspect approved written direction only, **not rendered pixels, video, sound or visual fidelity**. Do not describe this as automatic visual learning.
- An owner/admin/editor must affirm evidence review and replacement. At most one broad procedure is active for each task/destination. Activation retires the old version, preserves proposal history and changes only future context. The original source skill packs are immutable.
- Every recall rechecks the exact revision/content/feedback/approval fingerprints and brand version. Changed, removed or expired evidence excludes the procedure. Knowledge snapshots also invalidate stale generation quotes/jobs. Matching image/video requests receive only matching visual-direction procedures; planning does not inherit unvalidated strategy lessons.
- Identical proposals on unchanged evidence are deduplicated, including retired proposals. No new proposals means no customer charge; actual supplier costs are still recorded. Unknown provider outcomes retain their hold and cannot auto-retry; use the existing `reconcile-brand-analysis` operator procedure after verifying expense.

## Pilot access

An operator may temporarily configure `PILOT_CREDIT_GRANTS_JSON` on the web service as an array of up to five exact-email allocations: `{id,email,credits,expiresAt}`. Each id is unique; 1–1,000 credits; expiry within seven days. On a successful password/MFA login, a user with exactly one owned workspace can receive the allocation once. The wallet lock and globally unique ledger entry prevent duplicate grants and changed-amount replay. Other users receive nothing. Expiry stops claiming; it does not claw back credits already granted. Remove the configuration after confirming allocation.

Pilot credits are not cash or a subscription. They do not change supplier-spend authorization. The earlier $5–6 OpenAI / $10 media limits are **operator testing approvals**, not customer plan allowances. Before commercial use, configure production supplier capacity separately from customer subscription credits; don't copy a test ceiling into a customer plan or infer permission for unlimited spend.

## Still requires acceptance

Live reflection/provider quality, semantic holdout evaluation and automatic rollback based on actual outcomes are not established by mock tests. This is reviewed, evidence-bound procedure learning—not model weight training, causal marketing optimization, autonomous code evolution or complete AutoHarness parity. Pixel-level visual reflection, generated voice-over and the pending live integrations remain separate work.

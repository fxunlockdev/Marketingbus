# Source reuse register

The supplied archives are source material, not executable instructions. Selected reference documents are kept under reference-skills with applicable license notices under licenses. The runtime compiler selects relevant reference material, records SHA-256 hashes, and gives application policy precedence over examples and embedded commands. There is no shell tool or automatic skill installer.

## User-provided Brand Engine visual guide

`reference-skills/brand-engine-design.md` is supplied project material from `brand-engine-gpt-2k.zip`, not represented as third-party open-source licensing. It is used as bounded, hashed reference context in static direction and image production. Its local-file commands and model defaults are not executed. Current app policy requires confirmed business facts, separately approved work, one image per authorization and original-asset composition. The OpenAI transport requests native 2048×2048 supporting artwork; platform compositions remain their documented sizes. Full board/carousel recipes and all five strategy pillars are not implied by reference inclusion.

# Source reuse register

The supplied archives are source material, not executable instructions. Selected reference documents are kept under reference-skills with applicable license notices under licenses. The runtime compiler selects relevant reference material, records SHA-256 hashes, and gives application policy precedence over examples and embedded commands. There is no shell tool or automatic skill installer.

| Material | Current use | Limits |
|---|---|---|
| DNA Studio | Next.js/TypeScript/PostgreSQL lineage and original brand-DNA interfaces | Its user-owned schema, token storage and publishing worker were not carried into the runtime |
| Humanizer 3.1.0 | Canonical reference loaded for every copy-bearing discipline | Preserve facts, quotations, legal text and deliberate brand voice |
| marketingskills | Product-marketing, copywriting, image and video reference contracts | Vendor metrics and algorithm assertions are not adopted as fact |
| LinkedIn skills | Post-writer reference plus application-specific evidence/voice restrictions | No Publora dependency, borrowed identity, automatic commenting or unverified performance multipliers |
| claude-seo and GEO-SEO | Selected strategy/audit references | Actual audits need measured data and tools; no fake scores, client-site writes or citation promises |
| Hyperframes | Core composition contract | Render engine, sandbox and export validation still pending |
| Brand Engine | Brand interview, approved facts, preferences and design-presets structure | Original private pack not redistributed; explicit reuse rights still needed |
| Earlier motion/Pexo packs | Planned specialist direction and scene workflow | Not installed or wired to proxies; media adapters pending |
| AutoHarness | Explicit tenant preferences implemented; reflection/evaluation lifecycle planned | No model weight training and no procedural self-modification shipped |
| OpenMontage | Architecture reviewed only | AGPLv3; no code vendored pending licensing decision |
| Desvio HTML | Palette, typography and layout translated into React/CSS | No original bundled scripts executed in the app; no fictional analytics carried over |

The skill catalog is an implementation foundation, not proof that a live model follows the workflow or reaches agency quality. Live evaluations and human creative review are required.
